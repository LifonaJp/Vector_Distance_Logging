# Security Policy

## Supported version

Only the latest revision is maintained. This educational project is not a
security product and must not be used to make security or compliance decisions.

## Reporting a suspected disclosure

Do not open a public issue if you believe a file, commit, build artifact, or
repository setting exposes private information or credentials. Stop further
distribution, keep the suspected material out of chat and issue text, and use a
private security-reporting channel configured by the repository owner.

Until that private channel exists, retain the report locally and contact the
owner through an already established private channel. Never include credentials
or personal data in the first message.
